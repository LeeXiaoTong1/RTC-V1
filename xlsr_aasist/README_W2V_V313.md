# V3.13：同源判别一致性与困难真假区分

起点是用户已提交、反馈官方 Weighted **93.558** 的 V3.12 `last.pt`。之前官方 93.3941 与本地 Dev 96.316 属于原始模型；V3.12 last 的本地 Dev 是 96.295。不同数据集上的分数不能直接比较。93.558 是用户提供的官方结果，程序不会把它当作训练标签、调参目标或本地验收值。

本版是完整微调流程，默认最多四轮。编码器最后八层、MultiConv、分类器前层和现有有界特征修正继续更新；最终真假投影保持固定。检测器的推理结构不增加教师、语言识别器或模型融合。

## 主线一：处理条件变化后，保住正确的真假依据

同一来源按官方 Offline–Online CSV 的既有、经哈希验证的映射配对。禁止靠文件名猜配对。每次取完整录音的两个版本，二者都接受真实标签分类监督。

配对参考只来自标签判断正确且置信度至少 0.75 的一端，参考停止梯度；要求较弱的一端恢复有上限的正确真假间隔，目标上限 4、容许差值 0.25。若两端都错或不够确定，不会让错误预测互相强化。归一化特征的轻量一致性只在两端都判对时生效，不强行逐帧对齐，所以不假定延迟、静音和丢帧后每个时间点仍相等。

一致性直接作用于最终分类器使用的特征，没有另设一个可以自行完成辅助任务而不改善检测器的投影头。特征项权重为配对内部的 0.1。

## 主线二：把困难真音和相近假音分开

按 EN-real、EN-fake、ZH-real、ZH-fake 平衡来源抽样。每个损失小组八个来源、十六个音频版本，每个语言/类别有两个来源；同语言、同处理条件内才选择最相似或分数最混淆的反类样本。配对正例始终来自同一来源，重复抽到的来源有独立 occurrence 标记，不会串配。

采用两种直接作用于判别的约束：归一化特征中的局部分离，以及有界分数中的真假排序。对较难的来源增加有上限的分类权重，默认最多两倍，同时保持整个逻辑 batch 的损失总质量。极端错例不会无限支配更新。

真实语音不被压到一个共同中心：不同来源可保留不同说话人、内容和录音风格。此处采用实例正例，而非未经身份核验的说话人多中心；不能将本版称为完整复现 SAMO。

## 完整目标与数据预算

总损失为分类 + 0.1×配对 + 0.1×困难真假分离 + 0.1×正确参考保留 + 0.1×尺度约束 + 弱语言辅助。配对、分离在第一轮前四分之一逐渐启用，语言反向强度上限降为 0.005。语言探针仅作诊断，不要求语言识别率下降才能选中检测模型。

每个来源每次两个版本：请求配对约 50% 为官方 Offline–Online、25% 为 Offline–已有模拟处理、25% 为 Online–已有模拟处理；两个模拟版本轮换。缺少官方 Online 的来源使用明确记录的 Offline–模拟回退，不丢弃来源。实际计数见 `sampling_epoch_*.json`。

每个逻辑 batch 十六个来源，两个损失小组，最后只更新一次优化器。每个小组保留全部配对端点的计算图，内部继续按长度分组前向。没有逐帧硬对齐，也没有每步第二遍教师编码器。

默认完整执行最多四轮，普通停滞判定不会在第四轮前结束；非有限数、表征尺度异常或明显整体回退仍可提前停止。半轮验证保留，终端持续保留每次结果。

## 必须从实际 last 重新建立参考

启动时读取 V3.12 `config.json`、`completed.json`、`last.pt` 的训练游标和哈希，加载原始冻结部分后覆盖这份 last 的全部已训练参数。`best.pt` 即使是 baseline，也不会被代用。起点还会与原 last 的 Dev 分数重放对比。

旧 V3.7 特征不能冒充新 last 的输出。本版启动时只做一次冻结 Train 前向，按块保存每条录音的两个 logits 和一个特征 RMS。153,000 条约为 1.84 MB 的原始数值，加上小量压缩/元数据开销；中断可复用已核验的块。只对参考中已判对、足够确定的样本设置有上限的保留目标，不复制参考错误。

这一步有一次性计算成本。四轮中训练视图预算从旧方案约 16 个/来源降到 8 个/来源，加上约 4 个/来源的一次参考前向；这是计算量估算，不能据此保证 A100 耗时减少固定比例。配对小组保留更多计算图，峰值显存会增加。40GB A100 的实际吞吐、峰值由首轮日志测量；显存不足可在新启动时显式设 `--pair-micro-sources 4`，此时同组反类候选减少。

## 验收、保存、导出

固定本地 Dev 的定义和 0.5 阈值不变。相对于新起点比较 Weighted、Clean、Noisy、六个语言/处理组的真假 recall、AUC、相同 fake recall 下的 real recall。默认晋升最低 Weighted 增益 0.02 个百分点，Clean 最大回退 0.3 个点，分组 fake/real 最大回退 0.5/1.5 个点，AUC 最大回退 0.2 个点；Noisy 不允许回退，匹配 recall 允许最大 2 个点回退。这些是提前固定的工程验收设置，不是保证官方提升的统计结论，也不同于 V3.12 的严格设置。

独立语言诊断每种语言最多留出 64 个真实来源，较旧版的 256 个减少对稀缺 EN-real 的占用。另外按语言×真假各最多留出 64 个不参与本轮梯度训练的 Train 来源，保持其 Offline、Online 和两个处理版本一起，统计“原始判对、处理后新增错误”以及“原始判错、处理后救回”。这直接检查配对目标。旧模型曾见过这些 Train 来源，因此它是本轮适配留出诊断，不是未见语料泛化证明。

仅保存滚动 `last.pt` 和最终 `best.pt`，不按每轮生成完整编码器副本。起点原始权重和 **V3.12 last 都必须保留**。新运行启动时打印含原子临时副本的磁盘预算，不自动删除任何旧模型或数据。

`starting_last` 表示回退到此次官方 93.558 所对应的 V3.12 last；`epoch_*` 表示选中新训练权重；`last:epoch_*` 表示显式导出最后一次训练权重。元数据保存各自路径、哈希和源模型身份。

## 研究依据与验证边界

[TFCL](https://arxiv.org/html/2607.17761v2) 支持关注处理前后的判别稳定性，但论文包含时间软对齐和频率结构约束。本版是以完整录音特征为基础的项目设计，不是完整 TFCL 复现，不能套用论文涨分。

[SAMO](https://arxiv.org/html/2211.02718) 使用说话人多中心吸引子，提示真实语音存在多种正常模式。本版没有新增说话人标注或外部说话人模型，采用同源实例正例保留这些差异，不声称实现了该论文算法。

正确性验证包含真实小型 w2v-BERT 前向/反向、V3.12 last 起点重建、源配对隔离、损失梯度、原子断点恢复、导出顺序及 best/last 区分。这些检查不等同于真实 RTC 数据性能试验。尚未在正式 A100 数据上训练，不能承诺 Weighted 达到 97。
