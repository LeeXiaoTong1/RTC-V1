# V3.1：保留整段能力，补足短时含噪输入监督

本版本从已经验证过的 **V3 w2v-BERT 2.0 + MultiConv best** 继续适配。原 91.68 AASIST best、V3 的 best、原始语音和既有缓存均保留。默认来源为 `exp/w2v_v3_20260930_181111_5eca/best_model.pt`，对应该运行已选中的 `epoch_2_step_2417`；不会使用退化后的 `last.pt`，不会重新初始化后端。

这是基于诊断的候选训练配方，不是已验证的精度提升。所有 Dev 成绩是固定本地代理指标；平台成绩仍需正式评估。

## 为什么选择这项改动

已有 V3 best 的 Offline EN-real recall 为 91.20%，Seen/Heldout 只有 73.95%/74.80%。训练期间 noisy EN-real recall 约98.2%，不能将这理解为“模型还没有学会训练样本”。第三轮恢复最佳权重、降低学习率后的验证仍未超过 best，继续同样的训练组织缺乏明确收益。

逐样本分析中，1025个错误 noisy EN-real 视图里，有790个来自模型在整段原始语音上能够正确判断的录音。但原始 Dev 使用整段，noisy Dev 使用既有约4.04秒输入，因此不能把全部落差归因于加噪；时长、局部内容、归一化统计与处理链变化同时存在。

本次修复一个可以直接控制的缺口：整段训练没有显式要求模型仅凭短时上下文仍做出正确分类。模型架构、多层融合、四块 MultiConv、注意力统计池化保持不变。不同处理链、英文真实来源覆盖仍可能限制结果，本次不宣称已解决全部域差异。

## 实际训练配方

| 维度 | V3.1 设置 | 目的 |
|---|---|---|
| 初始化 | 完整加载当前 V3 best 的前后端；核查 SHA256 | 保留已获得的整段识别能力 |
| 原始与 noisy 数据 | ordinary 全遍历；每条 Offline Train 的两个整段 noisy 版本各遍历一次 | 不减少 fake 覆盖，不重新生成缓存 |
| 整段／短段监督 | 每条来源行保留完整视图；额外抽取3–6秒片段，首段／随机起点各50% | 同时学习完整与有限上下文 |
| 分类损失预算 | 同一来源行完整视图70%、短视图30%，总计100% | 防止增加视图等于重复加权 |
| 原本就短的录音 | 如果抽取长度不少于原长，仅使用原波形一次，损失权重合并为100% | 不重复计算相同输入，不拼接至4秒 |
| 特征处理 | 在波形上裁剪，再分别提取官方 fbank 和时间归一化 | 使短视图具有真实短输入的特征统计 |
| 真假与语言 | 维持原类别逆频率权重；所有语言、类别应用相同视图规则 | 避免再次叠加 real 或英文权重 |
| ordinary／noisy 损失份额 | 各50%，各自按原始来源行数归一化 | 不随新增短视图数量漂移 |
| 原增强 | ordinary 保留原 RawBoost 概率；noisy 不叠加二次增强 | 使用现有缓存的既定处理分布 |
| CKA | 权重0.01，仅计算原整段 logical batch | 不把同源短片段加入原块间多样性目标 |
| 可训练参数 | 编码器最后4层及原 MultiConv 后端 | 控制已有表示漂移 |
| 峰值学习率 | 编码器5e-8，后端2e-6；预热、余弦衰减 | 保守适配新目标 |
| 优化器 | 新目标从新的 AdamW 状态开始；运行内回退时恢复匹配的权重和 Adam 状态 | 明确区分新配方与原运行的断点继续 |
| 预算 | 最多2轮，每半轮完整 Dev；最多一次恢复并减半学习率 | 给恢复后至少两次验证机会，限制无效延长 |
| 推理 | 仍使用整段，阈值0.5，不增加多视图集成 | 保持部署接口与验证可比性 |

相同 source ID 在同一 epoch 的不同 noisy 版本使用同一裁剪随机方案（相同波形长度时裁剪位置相同），跨 epoch 改变。不同版本是不同训练行，分别保留原有损失预算。新视图不等于新增独立录音。

继承前版本对不足0.4秒输入的特征提取安全扩展；正常短语音不会被重复到4秒。额外短视图需要独立编码，这是不同输入的必要计算；同一完整波形不会重复读取、重复增强，也不会为 CKA 重新执行完整编码器前向。

## 选模与失败回退

训练前对起始 V3 best 再做一次相同 Dev 验证，保存为 `baseline`，不消耗训练轮数。即使新训练没有任何合格改善，新的 `best_model.pt` 仍是该起点的权重。

候选要同时满足以下条件，才会成为新的安全 best：

- Weighted 比当前安全 best 提高超过0.01个百分点；
- Noisy Macro-F1 不低于起始基准；
- Offline、Online、Seen、Heldout 的 EN-real recall 分别不低于起点减0.5个百分点；
- Seen、Heldout 的 EN-fake recall 分别不低于起点减0.3个百分点；
- Clean Macro-F1 不低于起点减0.2个百分点。

这些容忍度是明确的工程取舍，不是统计显著性声明。各条件均对固定起点保护，不允许多次小退步累计降低门槛。`best_weighted.pt` 与 `best_noisy.pt` 仍保留无条件指标赢家供复核，不能自动替代安全 best。训练报告分别展示四种英文 real 召回率。

## 启动

先确认旧 V3 已停止。新入口会检查活动作业并加锁；发现仍有训练、推理或缓存写入时拒绝启动，不会自动结束其他任务。

```bash
conda activate sdd
cd /home/ubuntu/LXT/RTC-w2v-improved &&
git pull --ff-only origin w2vbert2-balanced-robust-fast &&
cd xlsr_aasist &&
bash setup_w2v_v31.sh &&
bash run_w2v_v31.sh --source-run exp/w2v_v3_20260930_181111_5eca --upload-temp
```

使用现有 V3 环境即可，不增加依赖或替换 CUDA PyTorch。先核验文件及现有完整缓存、计算起始 Dev，再开始 `V3.1 joint epoch 1`。独立输出目录为 `exp/w2v_v31_...`，不会覆盖 `.latest_v3_run` 或旧运行文件。

实时进度：

```bash
bash watch_w2v_v31.sh
```

按 Ctrl+C 仅关闭查看器。查看已完成验证的完整表格，不会被动态进度覆盖：

```bash

```

后台日志仍定期保存进度。训练结束后诊断 ZIP 写入 `/home/ubuntu/LXT/temp`；`--upload-temp` 输出 temp.sh 下载链接，仅上传报告、标量和分数，不包含模型或音频。

## 恢复、诊断与提交

断点恢复沿用该 V3.1 运行保存的配方，核查代码、输入指纹和模型来源；不能用 V3 的 `last.pt` 启动 V3.1。半轮验证后的 `last.pt` 包含优化器、随机状态、数据游标和累计指标；未保存的步骤会重放。

```bash
bash run_w2v_v31.sh --resume "$(cat exp/.latest_v31_run)" --upload-temp
```

可选 GPU 流程检查（不会保存训练 checkpoint，也不会改变默认提交来源；不是精度验证）：

```bash
bash run_w2v_v31.sh --source-run exp/w2v_v3_20260930_181111_5eca --smoke-steps 2
```

正式评估使用 V3.1 的安全 best，沿用现有 Progress 协议：

```bash
bash run_eval_w2v_v31.sh --upload-temp
```

支持 `V31_RUN`、`V31_CHECKPOINT`、`EVAL_PROTOCOL`、`EVAL_AUDIO_ROOT`、`SUBMISSION_DIR` 覆盖。若最终报告的 `Promoted checkpoint` 为 `baseline`，表示没有合格改进；此时导出仍是起始 V3 模型，不能宣称升级成功。

不新增音频缓存。仍需要新运行的模型、优化器和报告空间；启动前会按实际模型大小检查保存及原子替换所需的磁盘余量，不会为腾空间自行删除 best 或缓存。

## 依据和边界

- [Transformers 4.38.2 官方特征提取实现](https://github.com/huggingface/transformers/blob/v4.38.2/src/transformers/models/seamless_m4t/feature_extraction_seamless_m4t.py)：每条波形的特征沿时间归一化。裁剪已归一化特征或完整编码器输出不等价于真正的短输入。
- [AASIST2，ICASSP 2024](https://arxiv.org/html/2309.08279v2)：研究了训练／测试时长不匹配与动态片段长度，不同测试集收益不一致。因此3–6秒及70/30是本次候选配方，不是论文证明的通用最优值。
- 对完整处理后音频再裁剪，不等于先裁剪后经过有状态 RTC 处理；本次直接改善时长、局部内容和归一化覆盖，无法据此保证所有未知处理链的泛化。
- 本次不同时叠加新的教师蒸馏、语言重采样、去噪网络或后端替换。训练数据仍仅使用官方 Train，保留现有训练噪声资源；Dev 仅用于固定验证及选模。

本地检查覆盖损失梯度等价、短视图归一化、完整数据覆盖、独立召回保护、真实小型 w2v-BERT 训练／恢复／导出；生产 GPU 显存与实际提分需服务器运行确认。
