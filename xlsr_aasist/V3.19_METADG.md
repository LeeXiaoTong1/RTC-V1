# V3.19：从 V3.18.9 best 增量训练一轮

这条实验继承 `w2v_v3189_20261016_183410_a437` 的 **best**，报告中为
`epoch_6_step_1403`。用户报告该版本 Progress weighted 为 93.82；
程序只通过 Train/Dev 训练与选模，不读取 Progress 标签或反馈进行调参。

仓库已经存在一个较早的 `w2v_v319` 实验。为避免覆盖它，新入口使用
`w2v_v319_meta` / `run_w2v_v319_meta.sh`，版本号为 **3.19**，
recipe 为 `v319_v3189_best_suffix16_first_order_metadg_v1`。
旧入口 `run_w2v_v319.sh` 不是本实验。

## 保留与变化

- 完整加载父 best 的 Omni 3B、60 层 LoRA 权重、多层融合、AASIST、
  重叠窗口/统计池化、分类器及冻结 PCL scale。
- **只更新最后 16 层 LoRA（第 45～60 层，一基编号）**。
  前 44 层已学到的 LoRA 增量继续参与前向，但不求梯度、不进入优化器、
  不启用 LoRA dropout。不会删除、清零或低精度合并这些增量。
- 融合与后端继续学习；编码器基座冻结。默认新增 **1 轮**，不重复头部预热。
- 从父 best 所在第 6 轮的实际学习率接续，重新建立 AdamW moments，
  本轮余弦衰减到起始值的一半。不会把父 last 的优化器与父 best 混用。
- 保留父模型的训练来源、每来源一次 Noisy 模拟及 RTC/活动抑制实现。
  **不加入 V4 的 Dev EN-real 转移、w2v-BERT/MHASP、PCGrad 或 XEUS**。
- 复用修正后的 PCM 来源登记表；主分类来源在 A/B 及 Online/Noisy 间均不重复，
  辅助参照只能属于 A 侧相同来源。官方无 Online 配对的 Offline 仍可参与 Noisy 分类。

## 元域更新

默认 E2，轮换 noise / rtc / joint 三种条件任务，A/B 方向定期交换。
每侧含 Online/Noisy × EN/ZH × Real/Fake 八个分类单元，各单元均值等权。
默认一轮维持父实验每流 `[9668,8000,8000,8000]` 来源访问量与 1403 次更新；
通常每次 A=24、B=24 个分类视图，末尾按准确预算缩小，不额外扩充训练集。

1. A 侧计算均衡 CE + 父模型双 PCL（包括其固定尺度、有效区间和方差约束）。
   原双 PCL 指 **模拟 Clean-RTC ↔ Noisy-RTC**，以及
   **官方 Online ↔ 模拟 Clean-RTC**；保持 V3.18.9 的定义。
2. 仅缓存可训练参数，以裁剪后的 A 梯度做一次临时 SGD 更新。
3. B 侧在临时参数上仅计算均衡真假 CE，不编码 PCL 参照。
4. 还原原参数后，用一阶梯度
   `(g_A + beta * g_B_at_temporary)/(1+beta)` 做一次 AdamW 更新。
   不计算二阶导数，也不在临时参数上执行 AdamW。

这里 A 的 `g_A` 包含 PCL；因此 PCL 在外层组合中随 `1/(1+beta)` 缩放。
这不是与普通父训练完全相同的目标。默认 beta 在 100 次更新内从小值升到 0.5；
不会照搬旧 15 轮实验的两轮预热，让这次一轮实验几乎没有元训练作用。

内层步长用 12 个固定 Train 任务（每类 4 个）标定，复用各任务波形和 RNG，
不看 B/Dev/Progress 来选步长。候选含 `1e-6` 到 `1e-1`；
沿用至少 9/12 个任务不增损、损失下降中位数 0.5%～5% 等检查。
若全部不通过，会保存原因并停止，不会静默将元训练变成 alpha=0。
标定和训练日志记录实际梯度、临时参数变化及稀疏 logits 变化。

## 评估和成果

完整沿用父实验保存的 Dev 音频及 `dev_partition.json`，不重新生成随机验证噪声。
父模型 best 是第 0 轮对照。只有本轮 Dev Select 原始加权 F1 提升才替换 best，
否则 `best_origin=v3189_parent`；本轮结果仍保存在 last。
提交沿用父系的 Dev calibration 和固定 0.5 判定接口。
旧 Dev 已参与历史开发，不能把它描述为从未使用的独立域外测试集。

报告包含父模型及本轮逐条 Dev logits、选模结果、来源审计、
可训练层清单、内层标定和外层更新诊断。不会上传模型权重或原始音频。
一个新增 epoch 只能提供初步信号，不能单独确认长期泛化收益。

## 更新与运行

先让当前 V4/V4.1 停在保存边界；新入口会拒绝与其他模型任务同时运行。
更新后使用已有 `sdd-v318` 环境，不需要 XEUS 环境。

```bash
cd /home/ubuntu/LXT/RTC-w2v-improved
git fetch origin
git switch --track origin/v3.19-parent-best-metadg

source "$(conda info --base)/etc/profile.d/conda.sh"
conda activate /home/ubuntu/LXT/v318-runtime/envs/sdd-v318
cd xlsr_aasist

bash run_w2v_v319_meta.sh \
  --parent-run /home/ubuntu/LXT/RTC-w2v-improved/xlsr_aasist/exp/w2v_v3189_20261016_183410_a437 \
  --epochs 1 \
  --submit-best \
  --upload-submission
```

若该分支已经存在，切换后使用 `git pull --ff-only origin v3.19-parent-best-metadg`。
默认提交协议和音频路径沿用 `/home/ubuntu/LXT/RTC/xlsr_aasist/dataset/` 下的
`progress.txt` 和 `wav/progress`；可通过原有 `--submission-protocol` /
`--submission-audio-root` 指定。上述上传只将生成的 scores/report ZIP 放到 temp.sh，
不会向竞赛平台自动提交成绩。

查看日志、保存暂停、断点恢复：

```bash
bash watch_w2v_v319_meta.sh
bash stop_w2v_v319_meta.sh
bash run_w2v_v319_meta.sh --resume "$(cat exp/.latest_v319_meta_run)"
```

启动器在独立会话运行训练。关闭日志查看器或对查看器 Ctrl+C 不会停止训练；
停止请使用上面的 stop 脚本，等出现 `PAUSED_RUN` 后再切换任务。
恢复使用已存 alpha、优化器、AMP scaler、RNG 和任务游标，不重新抽取先前完成的更新。

如需做同预算对照，在独立 run 使用 `--experiment E0`；
E0 保持相同来源任务、A/B 权重及 A 侧 PCL，只令内层 alpha=0。
不要通过对 Progress 反复试验来选择超参数。
