# V3.12：限制尺度失控，继续训练语言去偏

V3.11 报告里，一轮结束时 local Weighted 达到 96.616（同次原始模型 96.316），但没有通过完整分类保护条件。随后真实语音表征的方差相对原始模型增至约 85 倍、9,123 倍，最后约 520,882 倍。语言探针读得更差，并不能说明这类变化是有用的去偏。因此 V3.12 修正训练目标与更新方向，并在训练中直接检查尺度；继续训练原来的失控状态没有依据。

这里的 Weighted 是固定本地 Online Dev 代理指标，不是官方 Progress/Eval 分数。93.3941 是此前真实提交对应的官方结果。97 以上仍是目标，不是本版已验证的结果。

## 这次具体改变了什么

1. **从受保护的原始 best 重新出发。** 指定已完成的 V3.11 目录只用于核对权重来源。若其最终回退 baseline，就沿记录找到原始 checkpoint；不加载被拒绝的 `last.pt`。所有基础权重、数据和代码都有哈希校验。V3.11 真正选中过的新模型会被拒绝自动解包，避免悄悄丢弃已有改进。
2. **仍然进行实际微调。** 更新 w2v-BERT 后八层、MultiConv、第一层分类全连接和新增特征修正；冻结最后的二分类线性投影，使真假判别轴固定。真假分类监督仍可通过上游特征改变决策。编码器更早的层保持冻结。
3. **新增修正有明确幅度上限。** 残差从零开始；每条样本修正量的 L2 范数最多为输入特征的 20%。修正分支学习率从 V3.11 的 `1e-4` 降为 `2e-5`。这一上限只限制新增分支，不代表整个网络不会发生变化，因此还需要下面的约束。
4. **语言梯度不再直接推高 real 置信度。** 仍只对相同处理条件内的真实中英文语音训练语言判别器；向检测器回传时，去掉真假判别轴的两个方向，以及直接放大特征的径向分量。保留其余方向的训练空间。此为特征处的一阶梯度约束，不保证共享参数经 Adam 更新后分类绝对不变。
5. **补上双侧尺度约束。** 复用已有 Train 特征和分数，按录音取得参考特征幅度与置信度上限。特征 RMS 超出参考的 0.5–1.5 倍开始受罚；真假 logit 差的绝对值超出 `max(8, 1.5 × 原始绝对差 + 2)` 开始受罚，权重默认 0.1。这个上限不固定分数正负，不强迫模型保留原来判错的结果。原有正确样本的单侧保留约束继续使用，权重 0.2。
6. **异常提前结束。** 每个训练微批次在更新参数之前检查；RMS 超过参考 4 倍，或绝对 logit 差超过对应上限 4 倍，就停止。每半轮验证还检查各条件、语言、真假组的 RMS 和分数分位数：相对同次原始模型，特征/池化输入统计不能超过 2 倍，分数统计不能超过 3 倍；真实语音探针特征的总体及各条件方差比例须在 0.1–4 内。检查包含最大值，避免漏掉少数严重错误。发生异常时，不把这段未经验证的状态写入 `last.pt`，也不把探针下降记为去偏成功。

上述数值是本版明确、可审计的工程边界，尚未经过 A100 上本任务的大规模实验验证；不应通过不断放宽它们来掩盖异常。分类接受条件沿用 V3.11：同时看 Weighted、Clean、各组真假 recall、AUC，以及相同 fake recall 下的 real recall。语言信息更难读取和检测性能更好是两项独立证据。

## 部署与开始

在原来训练服务器的 `sdd` 环境内执行。下面指定的 V3.11 是本次已审计、最终选择 baseline 的目录。

```bash
conda activate sdd
cd /home/ubuntu/LXT/RTC-w2v-improved/xlsr_aasist
git pull --ff-only origin w2vbert2-balanced-robust-fast &&
bash setup_w2v_v312.sh &&
bash run_w2v_v312.sh \
  --source-run exp/w2v_v311_20261005_161841_6b5b \
  --upload-temp
```

默认最多四轮，包含每半轮固定 Dev 验证。常规停滞判定至少观察两轮；明显性能回退或尺度失控可提前停止。新版本是一次重新开始的训练，不能把 V3.11 的 `last.pt` 当成 V3.12 的续训状态。

终端会保留前面的结果，打印分类损失、尺度损失、特征/分数比例、每次更新耗时及每次验证结果。重新查看与停止：

```bash
bash watch_w2v_v312.sh
bash show_w2v_v312.sh
python -m w2v_v312.stop --apply
```

查看器中的 Ctrl+C 只关闭查看器；停止训练用上面的停止模块。若普通中断后需要继续，传入实际产生的 V3.12 目录：

```bash
bash run_w2v_v312.sh --resume exp/w2v_v312_实际目录 --upload-temp
```

续训使用已记录的配置，并重放上次完整验证之后尚未提交的步骤。已经完成（包括因尺度问题安全结束）的运行不会被此指令重新训练。

## 时间、磁盘与结果文件

- 每个微批次仍只做一次 SSL 前向及反向。新增约束作用于已经计算的小向量；没有第二套 SSL 教师，没有第二遍整模型推理。实际 A100 吞吐需要看日志，不能用 CPU 自检推断。
- 复用原音频和已有固定增强，不生成新一轮音频/帧缓存。仅从已有 Train 特征读取每条录音的参考标量。
- 保存一个滚动的 `last.pt`，包含可训练部分、Adam 状态及当前已选 best；完成后写一个 `best.pt`。冻结的编码器前缀通过原 checkpoint 引用，不重复保存，也不为每一轮留一份大权重。
- 开始时打印按实际参数量计算的磁盘预算，包含原子写入临时副本。训练报告只装诊断数据，不装权重或音频。
- `baseline_diagnostics.json`：同一执行策略下的原始特征与分数尺度。
- `training_history.json` / `report.md`：每次验证、收益与拒绝原因、尺度、真实更新耗时。
- `stability_stop.json`：触发异常的样本或分组、异常位置及最后可靠步骤。`completed.json` 分别记录实际完成和已提交的更新数，不会把丢弃的状态说成可以恢复。

检查最终 `V312_SELECTED`。若仍为 baseline，导出保留原始 best；不能据训练过程里一次 Weighted 上升声称新模型已获接受。

```bash
bash run_eval_w2v_v312.sh --upload-temp
```

完成导出后，可先预览本版自己的续训文件清理计划，再明确执行：

```bash
python -m w2v_v312.cleanup --run exp/w2v_v312_实际目录
python -m w2v_v312.cleanup --run exp/w2v_v312_实际目录 --apply
```

清理会保留 `best.pt` 和受引用的原始权重/缓存；删除续训状态后不能继续该运行。本版不会自动删除 V3.11 的诊断权重或其他版本的文件。
