# V3.10：直接训练检测特征的语言去偏

这次修正 V3.7–V3.9 的局限：不再冻结全部检测器后只修正最后的分数。以已核验、实际提交过的原始 best 为起点，直接微调 **w2v-BERT 最后 8 层、整个 MultiConv 和新的特征变换层**。原始 best 和已有音频保持原位，不生成新音频缓存。

这是一个完整训练版本；没有声称它已达到官方 Weighted 97。此前本地固定 Dev 的 96.316 与官方提交的 93.3941 属于不同评估条件，不能互相替代。代码测试通过也不等于泛化性能已验证。

## 目标与做法

1. **减少 EN-real 被当成 fake。** 每个逻辑 batch 的 EN-real、EN-fake、ZH-real、ZH-fake 各占四分之一源样本预算。每个来源的完整 ordinary 视图合计占 0.5，两个完整 noisy 视图各占 0.25。缺失 online 时不虚构配对，ordinary 预算归 offline。fake 保留明确分类监督。
2. **修正检测特征中的语言依赖。** 在 MultiConv 池化后、原真假分类器之前加入零初始化残差特征变换。原分类器使用修正后的特征。四个训练期语言分类器分别读 offline、online、noisy_a、noisy_b 的 **真实语音** 特征，学习分辨中英文；梯度反转让检测器在保持真假分类的同时，减少这些语言分类器可利用的信息。不对不同语言的 fake 强制对齐。
3. **允许上游一起调整。** 最后 8 层编码器和整个 MultiConv 一起训练。编码器最大初始学习率 2e-7、逐层乘 0.8；MultiConv 2e-6；特征变换与语言分类器 1e-4。分类学习率 warmup 后余弦下降，梯度反转强度在第一轮前四分之一从 0 增到 0.05。语言分类器从第一步正常学习。
4. **验证是否真的减少语言信息。** 从官方 Train 的 real 来源中划出中英文各至多 256 个来源（各语言 real 来源的至多 20%），全部视图一起退出本次主训练。其中一半训练独立语言探针，另一半测试；每次重新训练线性与小 MLP 探针，按处理条件分别测。主训练中的语言分类器失效不算证据。这些 Train 音频可能被原始 best 见过，因此这个诊断不冒充“全新语料测试”。

四个条件是可核验的处理类别，不是声称同一类别内所有平台、噪声参数和说话人完全相同。noisy_a/noisy_b 复用既有 V3.3 的两类模拟处理。我们仍需用固定 Dev 和实际官方评估检验跨条件泛化。

方法参考 [Ganin 等：Domain-Adversarial Training of Neural Networks](https://jmlr.org/papers/v17/15-239.html)。该论文提供梯度反转的基础方法；本项目的 real-only、按通信条件分组、局部编码器微调是任务适配，不是论文已经证明有效的 RTC 实验结论。

## 计算与磁盘

- 完整音频复用已经验证的原始 Train、V3.3 Train noisy 和固定 Dev。V3.7 特征缓存用于读取固定数据清单、核验来源和诊断历史数值差异；原 baseline 和探针特征在本次相同推理条件下重新测量。**新模型的训练与验证都重新经过可训练的编码器和 MultiConv**。没有从 V3.5 失败权重重新出发。
- 每轮源样本抽取预算约等于 Train 的来源数，默认 16 来源/逻辑 batch。少数组循环抽取，多数组按固定乱序跨轮接续；因此“1 epoch”是抽取预算，不保证该轮每个多数类来源都出现。日志保存各组数量、每段实际不同来源数，避免混淆。
- 默认最多 4 轮，每半轮固定 Dev 验证；仍保留提前止损，因此 4 轮是上限。学习率日程按实际配置轮数计算。不默认额外跑一个完整对照模型。显式 `--adv-weight 0` 可单独运行相同训练的去偏损失消融。
- A100 使用 BF16 训练，物理 microbatch 4、帧预算 2400、相近长度组批；最后可训练编码器层启用梯度检查点。每个物理小批立即反向释放激活；没有 CPU 激活卸载、额外教师编码器或对抗分支的第二次音频编码。
- DataLoader 预取 1，传递 NumPy，避免旧版跨进程 Tensor 文件描述符问题。每次更新打印 CE、language_CE、GRL、梯度范数、耗时和显存峰值。验证和导出为原完整音频、精确长度分组、FP32、固定阈值 0.5。
- **磁盘只存一份 `last.pt` 和完成后的 `best.pt`。** 只序列化发生训练的模型参数；冻结的编码器前缀由原 best 提供。`last.pt` 包含当前训练参数、Adam、随机状态、游标及已选 best 的部分参数。临时文件替换成功前保留旧 last；不保存每一轮的大 checkpoint。
- `storage_budget.json` 按实际参数量给出大小估计，启动打印原子写入所需空间并检查。不能把完整微调说成“只需几十 MB”：通常仍需数 GB，准确值以本机启动输出为准。不会再每轮生成约 32 GB WAV 缓存。
- 用标准 24 层 w2v-BERT 与默认 MultiConv 结构计算，本版约更新 1.96 亿参数，部分模型权重约 0.73 GiB；含 Adam、所选参数和写入余量的 last 预算约 3.47 GiB，原子替换峰值约 6.94 GiB。实际结构以加载到的 checkpoint 为准；这些是磁盘预算，不是 GPU 显存预测。
- CPU 上的完整模型训练会很慢；本地小模型测试验证实现，服务器 A100 的时长/显存/分数仍需实测。可以在**新运行**中用 `--microbatch 2 --frame-budget 1600` 降低峰值；不截断长音频。

## 选择与止损

候选需满足：Weighted 比原 baseline 至少 +0.1 个百分点、Noisy 不下降、EN-real 三条件平均至少 +0.5 个百分点；同时保留既定 EN/ZH fake/real、AUC、固定 fake recall 下的 real recall 保护线。Clean 最多下降 0.1、fake recall 每组最多下降 0.2 个百分点。比较固定基线，不随候选退步而降低标准。

语言探针单独记录：较强读出器的条件平均识别率至少下降 1 个百分点，原探针必须高于 55%，并检查特征没有整体塌缩。只有**检测提高且探针证据成立**才报告语言去偏证据；仅指标提高时明确称为微调收益，不将其包装成语言机制已证实。该诊断仍不是严格因果消融或“全部语言信息已删除”的保证。

连续两次验证没有更好的合格候选，或 Weighted 比起点下降超过 2 个百分点，就提前完成并导出已选 best；没有候选合格则沿用原始 best。不会以“还在适应”为由自动重复跑很多轮。`stop=True` 加 `complete` 表示触发了止损，不是崩溃。

## 部署与训练

启动回放修复：旧版直接比较当前前向与 V3.7 历史缓存，但旧缓存提取没有统一锁定 cuDNN TF32，且新版调整了分批，因此不能据此判断“零初始化模块改变了原模型”。新版使用原 Detector/MultiConv/Sequential 路径与新路径，在相同输入顺序、FP32、关闭 TF32 和相同分批下校验，保留原数值容差及分类结果一致要求。实际初始化或路径错误仍然报错；`startup_replay.json` 记录具体差值。

校验通过后，只在启动时增加一次完整 Dev 和少量探针样本的原模型推理。重新测量的原 best 作为本次所有候选的固定比较起点；旧缓存分数差异单独记录到 `baseline_cache_drift.json`，不计作训练收益。只持久化小体积分数与诊断，断点恢复复用已核验的结果，不重复完整基线推理，不生成 WAV 或完整特征缓存。

如果之前正是在 `Zero-adapter detector no longer reproduces the submitted base` 处失败，尚未更新参数。更新代码后使用下面的新启动命令；不要对旧失败目录使用 `--resume`，旧目录的代码指纹和 2 轮配置已固定。

```bash
conda activate sdd
cd /home/ubuntu/LXT/RTC-w2v-improved
git pull --ff-only origin w2vbert2-balanced-robust-fast
cd xlsr_aasist
bash setup_w2v_v310.sh
bash run_w2v_v310.sh \
  --source-run exp/w2v_v39_20261005_101913_96bd \
  --upload-temp
```

若运行目录名不同，可以省略 `--source-run`，按 `.latest_v39_run`、`.latest_v38_run`、`.latest_v37_run` 的顺序寻找；只接收已完成且 selected=baseline 的来源。会核对原始 checkpoint SHA256，绝不静默丢弃已经选中的其他修正。

原环境保持 torch、transformers 版本，不安装新模型/语言识别教师。启动先检测本目录仍在运行的训练进程，有占用时明确拒绝重复训练。显示器 Ctrl+C 只关闭查看，不会终止后台训练。

```bash
bash watch_w2v_v310.sh
bash show_w2v_v310.sh
```

真正停止本版本：

```bash
python -m w2v_v310.stop --apply
```

中断恢复，必须用实际 V3.10 运行目录：

```bash
bash run_w2v_v310.sh --resume exp/w2v_v310_实际运行目录 --upload-temp
```

恢复使用记录的原配置，从最后成功提交的验证边界继续；之后未保存的训练步骤会重跑，不谎称保留了中断瞬间的状态。第一次验证前停止则从原 best 重跑。已正常完成的运行不会重新训练。

## 提交与回收空间

```bash
bash run_eval_w2v_v310.sh --upload-temp
```

推理只有一个检测器及其特征变换，无语言标签、语言分类器或外部教师。`best.pt` 是部分权重，**必须同时保留配置引用的原始 best**；不会直接把很小的 `best.pt` 当成完整 w2v-BERT。提交 zip 仍只有按协议原顺序排列的 `scores.txt`，分数是 P(fake)。

训练结束、确认不需要优化器后，可以回收本版本的 `last.pt`：

```bash
python -m w2v_v310.cleanup --run "$(cat exp/.latest_v310_run)"
python -m w2v_v310.cleanup --run "$(cat exp/.latest_v310_run)" --apply
```

清理只针对该**已完成** V3.10 目录中的 `last.pt` 及其临时文件；必须核验 best 和原始依赖权重，拒绝路径链接越界。不会删除原 best、选中 best、共享音频、特征缓存、报告和仍需依赖的旧脚本。

报告含固定数据行清单、逐样本 Dev logits、每次验证指标、语言探针、样本预算和真实训练参数；上传超时不会把训练成功改为失败，本地 report.zip 保留。
